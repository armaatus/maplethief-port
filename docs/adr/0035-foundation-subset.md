# 35. Foundation subset: host categories on the bridged classes, collections without class clusters, save files in the data directory

- **Status:** Accepted
- **Date:** 2026-10-28
- **Issue:** #49
- **Builds on:** [ADR 0026](0026-objective-c-strategy.md) / [ADR 0029](0029-objective-c-runtime-services.md) (host classes, side-table state, autorelease pools), [ADR 0032](0032-corefoundation-object-model.md) (the bridged classes and CF's storage), [ADR 0034](0034-offline-services.md) (the data directory, the stubs' Foundation sends)
- **Amends:** ADR 0032's extension point "Foundation adds NS selectors to the method tables of `bridged_classes.cpp`": Foundation's selectors are host categories (#51's `mt_objc_host_category`, [ADR 0036](0036-coregraphics-and-uikit-drawing.md)) instead, and `+stringWithUTF8String:` / `-UTF8String` moved to Foundation

## Context

The game, its ObjC shell and the runtime's own host code send Foundation messages. Which ones is now generated: `python3 -m mtport.hostsurface generate` writes [re/host-surface.md](../re/host-surface.md) from #11's analysis (`work/re/imports.json`) — every (class, selector) that live game code sends to a framework class. Chartboost's sends and dead code are left out; untyped sends get their receiving class from a hand-kept table that generation checks both ways (no untyped selector without a receiver, no receiver entry nobody sends). The Foundation area is 78 selectors on 17 classes. Facts behind the decisions (armv7 slice):

- **Strings.** `NSString`/`NSMutableString` 19 selectors: `+stringWithUTF8String:`, `+stringWithCString:encoding:` (the Korean tables in EUC-KR, `0x80000940`), `+stringWithFormat:` / `-initWithFormat:` / `-appendFormat:` with `%@`, `-compare:options:` with `NSNumericSearch` (`+[GameCenterManager IsGameCenterAvailable]` compares `systemVersion` with `@"4.1"`), `-stringByAppendingPathComponent:`, `-isEqualToString:` (34 sends). NSString's UIKit drawing additions (`-drawAtPoint:withFont:`, `-sizeWithFont:`) belong to #51, whose classes are in another file.
- **Save files** ([formats/save.md](../formats/save.md)): raw binary files at `NSHomeDirectory()/Documents/<name>` (`0x6EF1`), written with `NSFileManager` `-fileExistsAtPath:` / `-createFileAtPath:contents:attributes:` and `NSFileHandle` `+fileHandleForUpdatingAtPath:` / `-writeData:` / `-synchronizeFile` / `-closeFile`, read with `-availableData` / `-readDataOfLength:` / `-getBytes:`. A slot is deleted through `NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES)[0]` and `-removeItemAtPath:error:`. `NSUserDefaults` and `NSKeyedArchiver` are Chartboost's only.
- **Bundle.** `-pathForResource:ofType:inDirectory:` (the sound loaders), `-objectForInfoDictionaryKey:` (`kCFBundleIdentifierKey`), and `-localizedStringForKey:value:table:` for every line of dialogue (`LocalizedCString` `0x6DD1`, table `Scripts`). Info.plist and all six `*.lproj/*.strings` files are **binary plists** (Info.plist 30 entries; `Scripts.strings` 2,219 and `ScriptExtra.strings` 527 in each language). `ResourceRules.plist` is XML, and only code signing reads it.
- **Collections.** Short lists: `CStateMainMenu`'s character slots (`NSMutableArray` of `NSNull`/objects), touch sets (`-allObjects`, 28 fast-enumeration loops over arrays and sets), `GameCenterManager`'s `NSMutableDictionary` cache, `+dictionaryWithObjectsAndKeys:` for the GL drawable properties.
- **Locale.** `+[NSLocale currentLocale]` `-objectForKey:NSLocaleCountryCode` (Korea shows the terms of service) and `+preferredLanguages`.
- **Dead senders.** `-[InAppPurchaseManager makePurchase:]` (the only `+[NSError errorWithDomain:code:userInfo:]` and `+[NSDictionary dictionaryWithObject:forKey:]` sends) and the other methods [re/objc-shell.md](../re/objc-shell.md) lists under "No selector reference" that are no framework callback have no caller.

## Options considered

**Where NSString's selectors live** (the bridged classes are CF's host classes, `bridged_classes.cpp`; #51 adds drawing selectors to the same class).

1. **Edit CF's method tables** (ADR 0032's plan). Foundation and UIKit would both edit one file and its arrays; a class's selectors from three issues in one table.
2. **Categories on the host class** at start-up through `mt_objc_override`. Works, but an override silently replaces a method, so two areas defining the same selector would go unnoticed, and overrides are meant for replacing image methods.
3. **Host categories.** `mt_objc_host_category {class_name, instance_methods, class_methods}` registered like host classes (one line in `runtime/src/objc/classes.cpp`); `mt_objc_add_host_classes` adds them after every class, with origin `MT_OBJC_HOST`. #51 (UIKit drawing, developed in parallel) added exactly this hook for its NSString drawing selectors; this issue had built an equivalent ("host method sets", which also rejected a selector two areas define) and dropped it on merging, so the runtime has one hook.

**Collections.**

1. **Class clusters as on iOS** (`__NSArrayI`, `__NSArrayM`, …). Faithful `-class` answers nobody asks for, and more classes.
2. **No clusters.** An instance is an object of the class it was made from; its contents are host state (a vector of retained guest objects). `[NSMutableArray alloc]` is an `NSMutableArray`, and an immutable class simply lacks the mutating selectors.

**Save files.**

1. **The guest path as a host path** under some root. The guest home is `/var/mobile/Applications/<UUID>`; mirroring it on the host is noise.
2. **The home directory maps to the data directory.** `<home>/X` → `<mt_stubs_data_dir()>/X`: the saves are `<data dir>/Documents/theif0` and so on, next to #52's `gamecenter.json`. The bundle stays read-only.

**Info.plist and `.strings`.** (a) Convert them with a tool at bootstrap; (b) a binary-plist reader in the runtime. The bundle is the shipped `.app` (ADR 0032), so (b): no derived files, and the reader treats every byte as untrusted.

## Decision

- **Files.** `runtime/src/foundation/`: `foundation.h` (the host API for UIKit, AVFoundation and the platform layer, plus the class and method-set declarations), `ns_string.cpp`, `ns_data.cpp` (NSData, NSNumber), `collections.cpp`, `plist.h`/`plist.cpp`, `ns_bundle.cpp` (NSBundle, NSLocale), `files.cpp` (NSFileManager, NSFileHandle, `NSHomeDirectory`, `NSSearchPathForDirectoriesInDomains`), `misc.cpp` (NSURL, NSError, NSThread, shared internals). Registry entries (`_NSClassFromString`, `_NSHomeDirectory`, `_NSSearchPathForDirectoriesInDomains`, the data import `_NSLocalizedDescriptionKey`) and host classes are under `#ifndef MT_HLE_CORE_ONLY`.
- **Host categories** (option 3) for `NSObject` (`-description`), `NSString`, `NSMutableString`, `NSData` and `NSNumber`, next to #51's NSString drawing category in `k_host_categories`. The API is #51's, in `maplethief/objc/objc.h`: `mt_objc_host_category`, `mt_objc_add_host_category`, `mt_objc_host_category_registry`. A category method replaces a class method of the same selector, so no two categories may define one selector: `objc.host_surface` and the Foundation tests look the selectors up.
- **Exactly the game's selectors.** The host classes implement the Foundation rows of `re/host-surface.md` plus what the runtime's own host code sends (#48's `[[NSDictionary alloc] init]` for resource properties, #52's `+arrayWithObject:`, `+setWithObject:`, `-allObjects`, `+isMainThread`, NSError for `-removeItemAtPath:error:`). Anything else is an unrecognized selector (`MT_TRAP_OBJC`), so a missing method shows up in the HLE report instead of returning a plausible nil. `NSLog`, `NSSelectorFromString`, `NSUserDefaults`, `NSKeyedArchiver` and `NSTimer` are Chartboost's and not implemented.
- **Strings** are CF's `__NSCFString` (ADR 0032): `+alloc` of `NSString`/`NSMutableString` returns an empty one that `-init…` fills. Formats use the libc printf engine (ADR 0028) on a copy of the registers and stack words, because `%@` sends `-description`, which clobbers r0–r3; `%@` of nil is `(null)`. `-compare:options:` implements `NSCaseInsensitiveSearch` and `NSNumericSearch` (digit runs compare as numbers). `-hash` is FNV-1a of the UTF-16 text, so equal strings hash equally whether constant or not.
- **Collections** without clusters (option 2). Fast enumeration copies items into the caller's buffer; `mutationsPtr` is a guest word that every mutation bumps (the compiled loop calls `objc_enumerationMutation` when it changes) and the object's `isa` for an immutable collection. Dictionary keys compare by text for strings and by value for numbers, else `-isEqual:`; a mutable-string key is copied. `NSNull`, the main bundle, the current locale and the default file manager are per-runtime singletons that ignore `-retain`/`-release` (retain count `UINT_MAX`).
- **Misuse raises** where Foundation raises (nil to `+stringWithUTF8String:`, `-addObject:`, `-setObject:forKey:`; an index out of range; mutating an immutable string): logged as `foundation: <method>: <what>` and stopped with `MT_TRAP_ABORT`, as the device's uncaught exception would.
- **Bundle and plists** (option b). `plist.cpp` reads `bplist00`: null, booleans, 1–16-byte integers, reals, dates, data, ASCII and UTF-16 strings, UIDs, arrays, sets and dictionaries with string keys; every offset, count and reference is bounds-checked, a reference cycle or a nesting deeper than 64 fails, and a file whose shared references would expand past a fixed number of objects is rejected. Each file is parsed once per CF configuration. `-objectForInfoDictionaryKey:` reads the localized `InfoPlist.strings` first (through CF's lookup, which falls back to `en.lproj` like CFBundle), then Info.plist. `-localizedStringForKey:value:table:` returns the table's value, else `value` if non-empty, else the key; nil table means `Localizable`.
- **NSLocale** answers from the configured language (`mt_cf_language`): country `KR`/`US`, language `ko`/`en`; `+preferredLanguages` is `[ko, en]` or `[en]`. Other keys are nil (logged).
- **Files** (option 2). `host_path(guest, for_writing)` maps `<home>/…` to `<data dir>/…` and, for reading only, the bundle's guest path to the extracted `.app`; any other path, or a `.`/`..` component, is refused (logged, nil handle, `NO`). `NSHomeDirectory()` is the directory that holds the bundle's guest path; `NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, …)` is `[<home>/Documents]`, other directories `[]`. `-createFileAtPath:contents:attributes:` creates `Documents/` when needed and replaces the file. A file handle keeps its offset as the game expects: writes at the current offset never truncate (the game rewrites whole files of a fixed size), `-truncateFileAtOffset:` truncates.
- **NSThread** `+isMainThread` is whether the sender's cpu is the runtime's main thread (GCD's workers are others, ADR 0033).
- **Per-runtime state.** Foundation's guest objects (singletons) are dropped when CF binds another runtime; `mt_cf::binding()` counts the bindings, so a new runtime at a reused host address does not see the old one's objects.

## Consequences

- **Tests.** In CI: `tests/cpp/foundation_test.cpp` (in `objc_test`) runs every class through the messages the game sends with the iOS argument layout — strings in UTF-8 and EUC-KR, `%@` formats whose later arguments survive `-description`, numeric compare, path components, NSData, NSNumber/NSNull, arrays/sets/dictionaries with fast enumeration and mutation detection, NSBundle and NSLocale over a synthetic bundle in both languages, the plist reader on synthetic files (every truncation and byte flip of a file, cycles, reference blow-up), the host categories (Foundation's and #51's selectors side by side on NSString, a test category, an unknown class), NSURL/NSError/NSThread/`NSClassFromString`, and the save files: the game's write and read sequences in one process, then the same files read back by a new runtime and guest memory (a restart), deletion through `NSSearchPathForDirectoriesInDomains`, and paths outside the home refused. `objc.host_surface` (`tests/cpp/host_surface_test.cpp`) looks every Foundation, GameKit and StoreKit row of `re/host-surface.md`, and the UIKit rows of #51's drawing classes (NSString's drawing selectors, `UIImage`, `UIFont`, `UIColor`, `UIBezierPath`), up in the registered host classes; UIKit (#54), OpenGLES (#117) and AVFoundation (M6) join it when they land. `tests/test_hostsurface.py` tests the generator on synthetic documents. Locally: `foundation.real_bundle` parses every binary plist of the `.app` and resolves all 2,746 keys of each language's tables through `-localizedStringForKey:value:table:`; `tests/test_hostsurface_real.py` checks that the committed table is current.
- **#52's test doubles are gone.** `stubs_test` and `stubs_real_test` run on the real Foundation classes.
- **A missing selector stops the game** instead of answering nil. That is the point (the HLE report names it), but a send the analysis typed wrongly will surface at run time; the fix is a row in `RECEIVERS` and the method.
- **No class clusters.** `[obj class]` of an array is `NSArray`/`NSMutableArray`, not `__NSArrayI`. No game code asks.
