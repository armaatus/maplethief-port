# A new character and the tutorial

{{npc:14}} teaches the basics on two small maps: talking to NPCs, taking a quest, jumping, climbing, using a portal, and attacking. Each lesson is a quest of its own, and the last one stays open until the portal of {{map:2-8}} ends the tutorial. Saving is refused on the tutorial maps, so the first save comes in {{map:2-0}}. The [beginner's guide](mechanics/beginners-guide.html) covers the same ground with the controls.
