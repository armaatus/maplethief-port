# About the game

This section keeps what is not gameplay: where MapleStory Thief Edition comes from, who made it, its versions and languages, what it ships but never uses, the bugs of the original, the online parts that no longer work, and how its files are built. The aim is that the knowledge survives even when the game can no longer be bought.

Facts on these pages come from the game's own files (version 1.5, read by the port's tools) unless a source is named beside them. Claims from outside the files, such as release dates, link to the page they come from.
