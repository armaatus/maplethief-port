The basic attack hits one monster in a box 60 by 24 pixels in front of the hero. With a dagger it is a swing that deals the base damage with no skill bonus; with a claw it is a punch for 1 damage.

## Strategy

It costs no MP and no stars, and before the first job advancement it is the only attack. A claw user throws stars instead ({{skill:1}}), and punches only when a monster is right next to the hero or the stars run out.
