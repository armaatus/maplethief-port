# Reverse-engineering notes

How parts of the original game work, as the port found them: the functions, the data and the rules, in words, with armv7 addresses and names. None of these pages quotes the game's code ([CONTRIBUTING](../../CONTRIBUTING.md#ground-rules)).

The pages marked *generated* are written by a tool from your own copy of the game, and *partly generated* ones have generated sections between `Generated by` comments: don't edit those by hand, rerun the tool the comment names. `scripts/re-analyze` rebuilds every names file, a clean Ghidra project with all names applied, and the generated pages that read its export. The Ghidra side and the **naming contract**, how any analysis names an address so that the name survives a re-import, are in [tools/ghidra/README.md](../../tools/ghidra/README.md#naming-contract).
